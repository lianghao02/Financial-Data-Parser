 金融資料 CSV 轉 Excel 解析工具 (Financial Data Parser) 離線使用說明
========================================================================

【免安裝快速使用方式】
1. 直接雙擊開啟「index.html」（使用 Chrome、Edge、Firefox 等任一現代瀏覽器）。
2. 將 CSV 或 ZIP 檔案拖曳至畫面虛線框內。
3. 選擇匯出模式（個別轉檔 / 智慧歸戶 / 資料整合）。
4. 點擊「立即轉檔」並下載產生的 Excel 檔案。

【資安保證】
本工具所有核心運算（CSV 解析、ZIP 解壓、Excel 建立）皆完全在您本機的瀏覽器記憶體內執行。
不使用外部伺服器，不回傳任何交易或個資資料，即使在完全中斷網路連線的離線電腦上亦可正常運作。
